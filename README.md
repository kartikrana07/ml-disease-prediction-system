#  ML Disease Prediction System

##  Project Overview

This project is a Machine Learning-based system that predicts multiple diseases using trained models.

### Diseases Covered:

* Breast Cancer
* Diabetes
* Heart Disease
* Parkinson's Disease

---

##  Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib / Seaborn

---

## 📊 Features

* Data preprocessing (imputers, encoders, scalers)
* Multiple ML models
* Prediction system using trained models
* Clean modular structure

---

## 📁 Project Structure

```
├── models/
├── scalers/
├── encoders/
├── imputers/
├── datasets/
├── app.py
├── requirements.txt
```
